## Agent 等待状态：agent 停下来等你时，菜单栏直接告诉你

### 新功能

- **菜单栏标记**：有会话在等待时，温度数字后追加 `⏸`；多个会话同时等待显示 `⏸2`、`⏸3`。没有等待时，外观与 0.7.0 完全一致。
- **面板三态**：agent 行显示「运行中 / 等待权限确认 / 等待输入 / 已完成」徽标，等待中的行排在最前。
- **本地通知**：会话从「不等待」变为「等待」时发一条系统通知，只带 agent 名、项目目录名和固定标签，不含命令原文。同一会话 5 分钟内不重复；`Stop` 后紧随的 `idle_prompt` 合并为一次。
- **功能开关**：`feature.agentStatus.enabled`，**默认关闭**。关闭时不读状态目录、不显示标记、不发通知，性能开销为零。

### 开启方式

右键菜单栏图标 → 「编辑规则文件…」，把 `feature` 段改成：

```json
"feature": {
  "agentStatus": { "enabled": true }
}
```

保存后重启 Manatee。首次收到等待时，系统会请求通知权限。

### 已知限制

- Claude Code 权限框出现到 hook 事件落盘约 6 秒，这是上游行为；hook 落盘后 Manatee 侧约 1 秒内显示 `⏸`。
- 拒绝通知权限时静默降级：只保留菜单栏 `⏸` 和面板徽标，不重复弹窗、不报错。
- 长等待靠进程存活佐证保留标记；状态文件超过 4 小时后一律不显示。
- 等待判定依赖 agent 侧 hooks 上报；没装 hook 时功能开启也不会出现 `⏸`。

```bash
brew update && brew upgrade --cask manatee
```
